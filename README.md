# Timber 2 Lumber LP

Timber 2 Lumber（ティンバートゥーランバー）の公式1ページLPです。

## 現在の構成

- `index.html`：ページ本体
- `styles.css`：デザイン
- 現在の購入導線：Creema
- 将来：Square公式オンラインストアへの導線を主CTAとして追加予定

## Cloudflare Pages で公開する場合

1. Cloudflare Dashboard で **Workers & Pages** を開く
2. **Create application** → **Pages** → **Connect to Git**
3. GitHub の `Timber2Lumber/timber2lumber-lp` を選択
4. Production branch: `main`
5. Framework preset: **None**
6. Build command: **空欄**
7. Build output directory: **/** または未指定でルートを使用
8. Deploy

静的HTML/CSSだけなのでビルド処理は不要です。

## 次に差し替えるもの

- 山桜シフトノブの実車写真
- 山に立っている木 / 丸太 / 乾燥材 / 完成品の写真
- Square Shop URL
- 独自ドメイン（例: timber2lumber.jp）
- 必要に応じて Amazon / 一の房 源 / 問い合わせ先

## ブランド方針

- CNCや自動加工機はブランドの主役として前面に出さない
- 「手加工のみ」と誤認させる表現もしない
- 木の来歴、自然乾燥、使う場面、仕上がりを中心に伝える
- 主力商品は木製シフトノブ
- 「木が立っているところから、製品になるところまで。」をブランドの核にする
